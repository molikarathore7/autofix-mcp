Exact bug: The get_email endpoint attempts to retrieve customer email using the key "email_address" instead of the correct key "email".
Explanation: A KeyError occurs because the dictionary key "email_address" does not exist in the customer object.
Suggest the fix: Replace "email_address" with "email" when accessing the customer dictionary.

Corrected code snippet:
@app.get("/customer-email")
def get_email():

    try:

        customer = customers[0]

        # Intentional Bug
        return customer["email"]

    except Exception as e:

        logging.error(f"Customer Email Error: {str(e)}")

        return {
            "error": str(e)
        }
