1. Identify the exact bug.
The get_email endpoint attempts to access the customer's email using the key "email_address" when the stored customer objects use the key "email".

2. Explain why it occurred in short one line.
A KeyError occurs because the dictionary key "email_address" does not exist; the correct key is "email".

3. Suggest the fix in short one line.
Change the dictionary access from customer["email_address"] to customer["email"].

4. Return the corrected code snippet.

    try:

        customer = customers[0]
